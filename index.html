💡 How Does It Work?

This project combines digital signal processing with a pretrained audio-classification model.

🎙️

Step 1: Audio Input

The browser reads the selected audio file and converts it into numerical samples.

〰️

Step 2: Signal Analysis

The waveform displays amplitude over time. FFT helps show the frequency components present in the signal.

🤖

Step 3: Classification

The pretrained YAMNet model analyzes audio and returns scores for sound categories. Relevant labels are grouped into animal categories by the application.

Important: A dominant frequency alone cannot identify an animal. The classification is an estimate from a pretrained model, and some sounds may be misclassified or returned as unknown. The model score is not a guarantee of prediction accuracy.
